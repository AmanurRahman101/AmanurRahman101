## 🚀 Featured Engineering

### 🛰️ Tawasol CRM: Enterprise Multi-Tenant Platform
*A comprehensive Customer Relationship Management system built with React, Node.js, and Express, featuring real-time communications and AI-driven automation.*

- **Multi-Tenant Architecture:** Engineered a highly normalized **MySQL** database supporting strict organization-based data isolation. Implemented hierarchical Role-Based Access Control (RBAC) accommodating Owner, Admin, Manager, Agent, and Viewer states.
- **Real-Time Communications:** Developed a live operational dashboard utilizing **WebSockets** for instant system notifications, paired natively with the **Agora SDK** to facilitate low-latency, real-time voice calling directly from the browser.
- **Agentic AI Integration:** Hooked into the **Gemini AI** API to power conversational chatbots. Users can bypass complex UI menus and converse naturally with the bot to execute deal tracking, contact management, and database CRUD operations.
- **Operational Logistics:** Built robust internal tooling for customizable deal stage pipelines, issue tracking modules, and comprehensive activity logging to audit all user actions across the platform. Fully HTTPS-enabled for mobile device support.

<br>

### 🛡️ NSU Plagiarism Checker: Localized AI Detection System
<img src="https://img.shields.io/badge/Status-Private_Repository-ff9e64?style=for-the-badge"/>

*An entirely offline, AI-powered academic plagiarism detection engine utilizing semantic vector similarity.*

- **The Architecture:** A fully localized runtime combining **React 19** and **FastAPI** with **SQLite** for robust persistent background job dispatching, per-user queue isolation, and hierarchical RBAC reference management.
- **The Intelligence:** Leverages **ChromaDB** and local **Ollama** embeddings (`nomic-embed-text` & `llama3.2:3b`) via LangChain to perform deep sentence-level semantic similarity matching and generate LLM-driven explanations.
- **The Engine:** Handles single, bulk, and raw text checks asynchronously. Persistent background processing continues server-side even if the client disconnects, automatically restoring the UI state upon return.
- **The Result:** Generates highly detailed, downloadable PDF reports featuring real-time highlight overlays and numbered source badges for academic review.
